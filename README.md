 # Netflix-Content-Analytics
 
 ## 📌 Project Overview
 The Netflix Content Analytics Dashboard is a data analytics project focused on analyzing Netflix's content library to uncover trends and business insights.
 The project analyzes 8,800+ Netflix titles using Python, and Power BI. Data cleaning, transformation, and exploratory data analysis were performed using Python (Pandas), followed by an interactive Power BI dashboard.

 ## 🛠️ Tools & Technologies
 - Python
 - Pandas
 - Jupyter Notebook
 - Power BI
 - Git & GitHub

 ## Dataset
 The dataset contains information about Netflix titles, including:
 -Show ID
 -Type
 -Title
 -Date Added
 -Release Year
 -Rating
 -Duration
 The dataset contains more than 8,800 Netflix titles.

 ## 🔍 Project Workflow
 ### 1. Data Cleaning & Transformation
 Python and Pandas were used to:
 -Identify and handle missing values
 -Clean and transform columns
 -Convert date-related fields
 -Prepare the dataset for analysis
 
 ### 2. Exploratory Data Analysis
 Exploratory analysis was performed to identify:
 -Movie vs TV Show distribution
 -Content release trends
 -Content additions over time
 -Popular ratings

 ### 3. Power BI Dashboard
 An interactive Power BI dashboard was created with:
 -KPI cards
 -Slicers
 -Charts and visualizations
 -Content distribution analysis
 -Release trends
 -Monthly content additions
 -Rating analysis
 The dashboard is divided into multiple report pages to keep the analysis clear and easy to navigate.

 ## 📈 Dashboard
 ### Dashboard Pages
 The Power BI report contains multiple views:
 -Overview
 -Content Profile
 -Trends
 These pages provide an interactive view of Netflix's content library and allow users to filter and explore the data.

 ## 💡 Key Insights
 Some of the key insights explored through the analysis include:
 -Distribution of Movies and TV Shows on Netflix
 -Growth of Netflix content over the years
 -Trends in content additions
 -Distribution of content across ratings
